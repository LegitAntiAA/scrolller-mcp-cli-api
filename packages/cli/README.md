# scrolller-cli

Terminal CLI for [Scrolller](https://scrolller.com) (unofficial) — search, download videos/images,
likes, comments, collections. Colored ASCII banner included. 😉

Full documentation: **[root README](../../README.md)**.

```bash
npm install -g scrolller-cli
scrolller download "burger" -n 10 -o ./dl
scrolller --help
```

Requires Node ≥ 22.19. NSFW content is opt-in (default `SFW`).
