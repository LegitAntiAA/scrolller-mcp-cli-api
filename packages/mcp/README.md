# scrolller-mcp

Model Context Protocol (MCP) server for [Scrolller](https://scrolller.com) (unofficial) —
47 tools that let AI agents search, download, like, comment and manage collections.

Connection guides for Claude Desktop / Cursor / Codex: **[root README](../../README.md)**.

```json
{
  "mcpServers": {
    "scrolller": { "command": "npx", "args": ["-y", "scrolller-mcp"] }
  }
}
```

Requires Node ≥ 22.19. NSFW content is opt-in (default `SFW`).
